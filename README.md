Proyecto challenger conversor de monedas el cual trata de convertir las firentes tipos de moneda en la de su preferencia y al terminar la de consultar la información le permitira 
tener un archivo Json que le permite mirar la tada consultada.
Librería:
se debe importar la libreria en su proyecto llamada gson-2.11.0.jar que la puede encontrar en https://mvnrepository.com/artifact/com.google.code.gson/gson
Para importar la librería en el editor de texto Intellij Idea debe realizar los siguientes paso:
1. Crear el proyecto.
2. darle clic en File
3. luego en project Structures
4. modules
5. Dependecias.
6. logo de +
7. irse al directorio en donde tiene la librearia y añadirla
8. luego dar ok y todo listo para usarla.
Luego ejecute el codigo ubicandose en el archivo llamado Principal.java e inicie su aventura.
